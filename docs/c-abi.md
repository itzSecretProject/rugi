# C ABI

Header: `include/rugi/rugi.h` (generated by cbindgen from
`crates/rugi-ffi/src`; `cargo test -p rugi-ffi` fails if it is stale).
C++ wrapper: `include/rugi/rugi.hpp` (header-only, C++17).
Library: `rugi_ffi` (`librugi_ffi.dylib` / `.so` / `rugi_ffi.dll` + import
lib; a static library is also built).

## Rules

| Topic | Contract |
|---|---|
| Handles | `RugiUi*` is opaque. Created by `rugi_ui_create`, destroyed by `rugi_ui_destroy` (NULL is a no-op). Every call checks the handle against the live handles first: a destroyed or foreign pointer, including a double destroy, returns `RUGI_ERROR_INVALID_ARGUMENT`. A destroyed handle's address may be reused by a later create. The handle passed to a frame callback is owned by `rugi_app_run` and valid only during the callback; destroying it returns `RUGI_ERROR_INVALID_ARGUMENT`, and begin/end frame on it return `RUGI_ERROR_INVALID_STATE`. |
| Threads | A handle may only be used on the thread that created it (checked: `RUGI_ERROR_WRONG_THREAD`). `rugi_app_run` must run on the main thread, once per process; on macOS another thread gets `RUGI_ERROR_WRONG_THREAD` without a window being opened. Calls from thread-exit destructors (C++ `thread_local`) are supported. |
| Strings in | UTF-8 `(const char* ptr, size_t len)`, borrowed for the call only; `(NULL, 0)` is "". Invalid UTF-8 returns `RUGI_ERROR_INVALID_UTF8`. A length or count above `PTRDIFF_MAX`, or a misaligned pointer, returns `RUGI_ERROR_INVALID_ARGUMENT`. `bool` arrays and fields may hold any byte; nonzero is true. |
| Strings out | Caller-provided buffers. `rugi_text_input` edits a NUL-terminated buffer in place and never writes past `buf_size` (truncates on a character boundary). `rugi_last_error_message(buf, size)` returns the size needed. `rugi_lucide_icon` returns 0 when `out` is too small; `rugi_keybind_label` returns the length without the NUL. |
| Enums | `uint32_t` constants (`RUGI_BUTTON_*`, …); unknown values return `RUGI_ERROR_INVALID_ARGUMENT`, never UB. |
| Structs | Plain C structs. Descriptors start with `struct_size` (ABI versioning). `rugi_abi_version()` must equal `RUGI_ABI_VERSION`. |
| Errors | Functions return `RugiResult`; widget functions return `bool` and record errors the same way. `rugi_last_error_code()` / `rugi_last_error_message()` are thread-local. Each call reports its own errors; nothing carries over to a later call. API misuse (widgets, styles or ids pushed outside a frame, unbalanced `begin`/`end`) is `RUGI_ERROR_INVALID_STATE`; unclosed containers are auto-closed and unpopped id scopes reset at the next frame. A `begin_*` that rejects its arguments still opens an empty group, so the matching `rugi_end` stays balanced. |
| Floats | `rugi_ui_begin_frame` rejects a NaN, infinite or negative size and a scale that is not finite and positive (`RUGI_ERROR_INVALID_ARGUMENT`); finite sizes are clamped to 0..1e6, scales to 1/16..16, and a non-finite `dt` uses a default step. Input events with NaN coordinates or deltas are ignored (the pointer keeps its state); infinite ones are clamped to ±1e6. A non-finite rect, slider or spin-box bound, table height or width, scroll-area height, font scale or text size returns `RUGI_ERROR_INVALID_ARGUMENT`; other non-finite floats are sanitized. Primitives with non-finite geometry are never drawn. |
| Panics | Every entry point catches Rust panics and returns `RUGI_ERROR_PANIC`; functions returning `bool` or `size_t` return false/0 and record it. Destroy the handle afterwards. |
| Callbacks | `RugiFrameCallback`, `RugiTableCellFn` and `RugiCarouselCardFn` must not throw or `longjmp` through Rugi. The C++ wrapper's trampolines catch exceptions and rethrow the first one after the Rugi call returns (`run_app`, `Ui::table`, `Ui::carousel`). |
| Re-entrancy | Table cell and carousel card callbacks receive the same `RugiUi*` and may call any widget or layout function on it, including nested tables and carousels. `rugi_ui_destroy` and begin/end frame return `RUGI_ERROR_INVALID_STATE` there. Rugi holds no Rust reference to the handle across the callback. |
| Icons | `RugiIcon` is a built-in vector icon (`RUGI_ICON_*`) or a font glyph `RUGI_ICON_GLYPH_FLAG | codepoint`. `rugi_icons_lucide.h` provides `RUGI_ICON_LUCIDE_<NAME>` values and `RUGI_LUCIDE_<NAME>` UTF-8 literals for use inside labels. |
| Versioning | `RUGI_ABI_VERSION` is 1. Within a version, changes are additive: functions, constants and struct fields are only added, never removed or reordered. Descriptors start with `struct_size`, so a program built against an older header keeps working: a `RugiAppDesc` whose `struct_size` ends before `window_flags` is accepted. |
| Ownership of values | The application owns widget values (`bool*`, `float*`, text buffers); Rugi only reads/writes them during the call. |

## Minimal C

```c
RugiUi* ui = NULL;
rugi_ui_create(NULL, &ui);
RugiFrameDesc fd = {1280, 800, 2.0f, 1.0f / 60};
rugi_ui_mouse_move(ui, 100, 40);
rugi_ui_begin_frame(ui, &fd);
rugi_begin_central_panel(ui);
if (rugi_button(ui, "Save", 4, RUGI_BUTTON_PRIMARY, RUGI_ICON_NONE)) { /* ... */ }
rugi_end(ui);
rugi_ui_end_frame(ui, NULL);
rugi_ui_destroy(ui);
```

## C++

```cpp
rugi::run_app({"My tool"}, [&](rugi::Ui ui) {
    ui.central_panel([&] {
        ui.title("Hello");
        if (ui.button("Save")) save();
        ui.slider("Gain", gain, 0.f, 1.f);
        ui.text_input("name", name, "Name");
    });
});
```

Containers in the wrapper close via RAII even if the body throws.

`rugi_show_demo(ui)` / `ui.show_demo()` renders the built-in demo from C or
C++; `rugi_set_demo_page` selects a page.

```cpp
#include <rugi/rugi_icons_lucide.h>
ui.menu("File", [&] { if (ui.menu_item("Save", "Ctrl S")) save(); });
ui.button("Export", rugi::ButtonKind::Secondary, RUGI_ICON_LUCIDE_DOWNLOAD);
ui.combo_box("backend", backend, {"Vulkan", "Metal", "DX12"});
ui.table("rows", {"Name", "Size"}, {3.f, 1.f}, 100000, selected, 400,
         [&](rugi::Ui cell, size_t row, size_t col) { cell.label(name(row, col)); });
ui.with_color(RUGI_COLOR_ACCENT, {0xF7, 0x64, 0x8E, 255}, [&] { ui.button("Danger zone"); });
if (auto cmd = ui.command_palette({{"New file", "Ctrl N"}, {"Toggle theme", ""}})) run(*cmd);
```

## Custom chrome and glass

A borderless window with a glass panel over an animated backdrop, as in
[examples/cpp-glass/main.cpp](../examples/cpp-glass/main.cpp):

```cpp
rugi::AppConfig cfg;
cfg.window_flags = RUGI_WINDOW_BORDERLESS;           // | RUGI_WINDOW_TRANSPARENT | RUGI_WINDOW_FIXED_SIZE

RugiBackdrop bg = rugi::backdrop_preset(RUGI_BACKDROP_AURORA);  // edit colors/speed freely
RugiGlassStyle glass = rugi::glass_style(RUGI_GLASS_FROSTED);
uint32_t page = 0;

rugi::run_app(cfg, [&](rugi::Ui ui) {
    RugiRect s = ui.screen_rect();
    ui.backdrop(bg);
    ui.glass_panel(rugi::rect(40, 40, s.w - 80, s.h - 80), glass, [&] {
        ui.title_bar("Settings", 30);                  // drag + minimize + close
        ui.segmented("pages", page, {"Backdrop", "Panel", "About"});
        ui.transition("page", page, rugi::Slide::Up, [&] {
            ui.slider("Speed", bg.speed, 0, 2);       // edits the backdrop behind the panel
            ui.slider("Size", bg.scale, 0.5f, 2);
        });
    });
});
```

| Function | Notes |
|---|---|
| `rugi_glass_style_preset`, `rugi_backdrop_preset` | Fill a `RugiGlassStyle` / `RugiBackdrop` with defaults. Plain structs, so edit any field. |
| `rugi_backdrop`, `rugi_backdrop_rect` | Animated GPU backdrop for the window or a rounded rect. |
| `rugi_glass`, `rugi_begin_glass_panel`, `rugi_begin_glass_card` | Glass surface, floating panel or content-sized card; close containers with `rugi_end`. |
| `rugi_begin_region` | Layout at an explicit rectangle (clipped). |
| `rugi_begin_transition` | Content fades and slides in when `key` changes. |
| `rugi_title_bar`, `rugi_window_command`, `rugi_screen_rect` | Custom window chrome for borderless windows. |
| `rugi_ui_set_ambient_fps` | Frame-rate budget for animated backdrops while focused / unfocused (0 = display refresh; defaults 0 / 30). |
| `rugi_keybind`, `rugi_bind_active`, `rugi_keybind_label` | `RugiKeyBind` is a plain struct, so zero-initialize it for "unbound". |
| `rugi_multi_select`, `rugi_segmented`, `rugi_rail_item`, `rugi_icon_button`, `rugi_page_dots`, `rugi_text_centered` | Widgets. |
| `rugi_text_input_ex` | `RUGI_INPUT_PASSWORD` and a leading icon. |
| `rugi_carousel` | `RugiCarouselCardFn` paints each visible card. The callback re-enters Rugi with the same `ui` (like the table). `rugi_last_item` reports a click on the centered card. |

The key set covers every letter, digit and function key, plus Insert and the
modifier keys (`RUGI_KEY_NUM0 + n`, `RUGI_KEY_F1 + (n - 1)`). The theme
presets `RUGI_THEME_ROSE`, `_MOCHA`,
`_FOREST` and `_GRAPHITE` work in `RugiUiDesc`, `RugiAppDesc` and
`rugi_ui_set_theme`.

See [custom-ui.md](custom-ui.md) for the Rust equivalents and screenshots.
